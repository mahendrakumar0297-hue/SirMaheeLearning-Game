# 🎈 बच्चों का मज़ेदार एजुकेशन लर्निंग गेम (Kids Educational Web Game)

यह बच्चों के लिए एक आकर्षक, रंगीन और इंटरएक्टिव वेब-आधारित लर्निंग गेम है। इसमें गणित, सामान्य ज्ञान/स्पेलिंग क्विज़ और मेमोरी मैचिंग गेम्स शामिल हैं।

## 📁 प्रोजेक्ट फ़ाइलों की सूची (Files in Repository)
1. `index.html` - गेम की मुख्य HTML संरचना
2. `style.css` - सुंदर रंगीन स्टाइलिंग (CSS)
3. `script.js` - गेम का पूरा लॉजिक और इंटरएक्टिविटी (JavaScript)
4. `README.md` - प्रोजेक्ट विवरण और निर्देश

## 🚀 रिपोजिटरी में कैसे अपलोड करें (GitHub / Web Host):
1. अपने GitHub एकाउंट पर एक नई रिपोजिटरी (New Repository) बनाएं।
2. `Upload files` विकल्प पर क्लिक करें।
3. एक-एक करके `index.html`, `style.css`, `script.js` और `README.md` फाइल्स को अपलोड करें।
4. `Commit changes` पर क्लिक करके सेव करें।
5. GitHub Pages चालू करके गेम का आनंद लें!

## 🌟 फीचर्स (Key Features)
- 🔢 **गणित का जादू:** जोड़-घटाव के त्वरित प्रश्न
- 🦁 **शब्द व चित्र ज्ञान:** पशु, फल और रंगों के चित्र क्विज़
- 🃏 **यादाश्त का खेल:** मेमोरी कार्ड मैचिंग
- ⭐ **स्कोर व स्टार्स:** सही उत्तर देने पर स्टार्स और सेलिब्रेशन एनीमेशन
